# Windows Visibility & Investigation Lab (Sysmon)

This project demonstrates how endpoint visibility using Sysmon supports security investigation,
triage, and incident response from a SOC Tier-1 / Security Tech Support perspective.

## Project Goals
- Increase visibility beyond standard Windows Security logs
- Understand parent-child process relationships
- Correlate process activity with network behavior
- Practice Tier-1 classification: Noise / Exposure / Incident
- Document findings in an escalation-ready format

## Lab Environment
- Windows 10 endpoint (Sysmon installed in the lab)
- Event Viewer (Microsoft-Windows-Sysmon/Operational)
- Defensive analysis only
